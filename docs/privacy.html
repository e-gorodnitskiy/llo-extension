Privacy Policy — Progress Tracker for LLO.lu

Last updated: 14 May 2026

In this policy, "the extension" refers only to the Progress Tracker for LLO.lu browser extension. The extension is an independent project and is not affiliated with, endorsed by, or connected to llo.lu, the Institut National des Langues Luxembourg, the Luxembourg Ministry of Education, or ALTISSIA INTERNATIONAL S.A. This policy does not cover llo.lu itself; for that, see llo.lu's privacy policy.

The extension exists because in January 2026, LLO.lu redesigned its platform to open access with no account creation required, and the previous built-in progress tracking was discontinued. This extension is an independent, local-only tool that lets learners keep their own progress history on their own device.

Short version

The extension reads information already shown on llo.lu pages in your own browser (which exercises you complete and your scores) and stores it locally on your device. It does not make any network requests, send anything to any server, contact the developer, or share any data with third parties. There is no account and no telemetry.

What data the extension reads

While you have an llo.lu page open, the extension reads the following from that page only:

  • The URL path, to detect when you are on a lesson or activity page.
  • The page's own state object (the Inertia data-page attribute that llo.lu already renders into the DOM) — used to identify the current activity, lesson, level, theme, and interface language.
  • For scored exercises: the percentage score shown on the result screen at the end of the exercise.
  • For theory activities (grammar rules, vocabulary lists, videos, flashcards): the fact that you stayed on the page for at least 5 seconds.

The extension only activates on URLs matching https://llo.lu/*. It has no host permissions for any other site and reads no data anywhere else.

What data is stored, where, and for how long

The data above is written to chrome.storage.local — an area of your own browser's storage that is local to your device. Stored records contain:

  • The activity code, lesson code, level, theme, and language tag (short identifiers used by llo.lu, e.g. LB_LU_A1_GRAMMAR_W_FRO_WAT).
  • The activity name and lesson name as shown by llo.lu.
  • For scored exercises: best score, last score, attempt count, pass/fail flag, and timestamps of first and last completion.
  • For theory: view count and timestamps of first and last view.
  • A cache of which activities each visited lesson contains, so the extension can show accurate "done / total" badges.
  • Your settings (currently just the "show progress badges" preference).

Records persist until you remove them. You can delete all data at any time using the Reset Data button in the side panel, or by removing the extension from Chrome.

What the extension does NOT do

  • It does not make any HTTP, fetch, WebSocket, or other network requests of its own. No connection to the developer, no analytics, no remote logging, no remote configuration, no automatic updates of tracked data.
  • It does not send data to llo.lu either; it only reads what your browser has already rendered locally.
  • It does not transmit, sell, share, or otherwise transfer your data to any third party.
  • It does not use your data for advertising, profiling, or any purpose unrelated to the single feature of showing you your own progress.
  • It does not read or store passwords, authentication tokens, cookies, or personal account information.
  • It does not modify llo.lu's content or behavior; it only appends small status badges as sibling elements alongside existing links.
  • It does not run on any website other than llo.lu.

Permissions, explained

  • storage — required to save your progress records in your own browser via chrome.storage.local.
  • sidePanel — required to show the progress overview panel when you click the toolbar icon.
  • Host permission for https://llo.lu/* — required so the content script can read the page state on llo.lu in order to identify activities and capture scores. The extension has no permission to read any other site.

Export

The side panel includes an Export JSON button. When you click it, the extension creates a JSON file containing your records and settings and triggers a download via your browser. The file is saved wherever your browser saves downloads. The export is initiated only by your click; the extension never exports data on its own or sends the exported file anywhere.

Changes to this policy

If the extension is ever updated in a way that changes how it handles data — for example, by adding any kind of network request, cloud sync, telemetry, or third-party service — this policy will be updated and the change will be noted in the repository's release notes before that version is published.
